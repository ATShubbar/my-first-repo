# Starting point: new to Python, learning algo trading from scratch (crypto, paper-first)

The learner is **new to Python** and wants to **learn algorithmic trading from first principles** by building a crypto trading bot with Claude Code, starting with backtesting and paper trading before any real money. This sets the floor for every future session: language fundamentals must be taught alongside trading concepts (never assumed), and all execution stays simulated until a strategy is validated.

## Evidence
Established directly via the mission-scoping interview at the start of the first `/teach` session (goal, Python level, market, and risk appetite all stated explicitly).

## Implications
- Lessons must teach Python constructs on first use; cannot lean on prior programming knowledge.
- Sequence is concept → backtest → paper trade → (much later) small live trades.
- Heavy frameworks (Freqtrade, FreqAI/ML) are out of the zone of proximal development for now — revisit after a simple rules-based strategy is understood end to end.
