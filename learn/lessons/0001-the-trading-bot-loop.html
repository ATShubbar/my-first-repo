The Trading Bot Loop

Every trading bot ever written — from a 20-line hobby script to a hedge fund's black box — is the same five-step loop running over and over. Learn the loop and you have the skeleton that all the rest of this course hangs on.

The one idea

A trading bot is not magic and it is not (mostly) about predicting the future. It is a loop. It looks at the market, decides what to do, acts, and waits — then does it all again. The whole craft of algorithmic trading is making each of these five steps a little less wrong.

  1. Get market data. Ask the exchange: what is the price right now? What were the last 100 prices? In crypto this comes from an API — we'll use a Python library called ccxt that speaks to 100+ exchanges with the same code.
  2. Compute a signal. Turn that data into a number or a verdict: buy, sell, or do nothing. This is "the strategy" — and it's only one of five steps.
  3. Check the rules (risk). Before acting, ask: can I afford this? Is the position too big? Have I lost too much today? This step is what keeps you solvent.
  4. Place an order. Send the buy/sell to the exchange — or, in paper mode, only pretend to. Same logic, no real money.
  5. Wait, then repeat. Sleep a few seconds, minutes, or hours, then loop back to step 1.
  6. ↑ repeat forever ↑
Why this matters for you: you chose to paper-trade first. Paper trading changes exactly one step — step 4 becomes "simulate the order instead of sending it." Steps 1, 2, 3, and 5 are identical to a live bot. That's why a paper bot is such an honest rehearsal: only the money is fake.

The beginner's trap

Newcomers pour 95% of their energy into step 2, the strategy — hunting for the magic formula that predicts price. But the traders who survive obsess over steps 3 and 5: risk limits and disciplined, repeatable execution. A mediocre signal with great risk control can endure. A brilliant signal with no risk control blows up. We will respect all five steps.

Where the danger hides

Because the loop is so simple, it's tempting to test a strategy on past data, see big profits, and rush to real money. That past-data test is called a backtest, and it lies more often than it tells the truth — through overfitting, look-ahead bias, and ignored fees. We'll spend real time learning to read a backtest skeptically (QuantStart, common pitfalls). For now, just hold the loop in your head.

Check yourself

Don't re-read — try to recall. Answer before you reveal; getting it slightly wrong now is how it sticks.

Which single step changes when you switch a bot from live trading to paper trading?

Why: Paper mode only simulates the order in step 4. Data, signal, risk checks, and the loop timing all run exactly as they would live — which is what makes paper trading a faithful rehearsal.

A trader brags their signal predicts price brilliantly but ignores position sizing. What's the real risk?

Why: Step 3 (risk) is what keeps you solvent. A great signal with no risk limits is one unlucky streak away from ruin — survival depends on sizing and limits, not just prediction.

In step 1, what does the Python ccxt library give you?

Why: ccxt is a unified API — the same Python code fetches prices and (later) places orders across 100+ exchanges. It supplies data and execution plumbing, not a strategy and not an edge.
