Your First Market Data in Python

Last lesson, step 1 of the loop was "get market data." Today you make it real: three lines of Python that ask a live exchange for the current price of Bitcoin. No API key, no signup, no money. Your first tangible win as an algo trader.

The three lines

Here is the entire program. Read it once; we'll take it apart line by line right after.

import ccxt

exchange = ccxt.binance()
ticker = exchange.fetch_ticker('BTC/USDT')

print(ticker['last'])

Run it and it prints something like 67432.10 — the most recent price Bitcoin traded at, in US-dollar-pegged tether (USDT), fetched live from Binance the instant you ran it.

No account needed. Reading public prices is anonymous — you only need an API key later, to place orders. That's why this is a safe first step: ccxt tutorial, ccxt docs.

Line by line (you're new to Python — nothing assumed)

import ccxt

A library is a bundle of code someone else wrote that you borrow. ccxt is the library that knows how to talk to 100+ crypto exchanges. import is how Python pulls a library into your program so you can use it. You install it once from your terminal first:

pip install ccxt

pip is Python's package installer — think "app store for libraries." (Ask me if pip isn't found; setup is the one part worth doing together in Claude Code.)

exchange = ccxt.binance()

The = sign stores something in a variable — a named box. Here we ask ccxt to build a Binance connection object and we put it in a box called exchange. The () means "make one now." Want Kraken instead? ccxt.kraken() — same code everywhere, which is ccxt's whole point.

ticker = exchange.fetch_ticker('BTC/USDT')

A method is an action an object can do, written object.action(). fetch_ticker asks the exchange for a snapshot of one market. 'BTC/USDT' is the symbol: trade BTC priced in USDT. What comes back is a dictionary — a set of labelled values (last price, bid, ask, high, low, volume…).

print(ticker['last'])

Square brackets pull one labelled value out of a dictionary: ticker['last'] is the last traded price. print(...) shows it on screen. Swap in ticker['bid'] or ticker['high'] to see other values — same dictionary, different label.

You just built step 1

That's not a toy. Every bot — including the one you'll eventually paper-trade — starts exactly here: a variable holding an exchange, a call that fetches data, a value read out of the result. Lessons 3+ add a signal on top of this. The foundation is now under your feet.

Check yourself

Recall first, then reveal. A wrong guess now is how it sticks.

What does the line import ccxt actually do?

Why: import brings an already-installed library into your program. Installing it is a separate one-time step with pip install ccxt.

Why does this program need no API key or account?

Why: Market data is public, so anyone can read it anonymously. You only need an API key later, when you place orders that move money.

In ticker['last'], what is the role of 'last'?

Why: fetch_ticker returns a dictionary of labelled values; ['last'] picks the one labelled "last" — the most recent traded price.

Now you try (tight feedback loop)

This is where knowledge becomes skill. Do this and you'll feel step 1 working:

  1. In Claude Code, run pip install ccxt, then put the three lines in a file called price.py and run python price.py. Did a number print? That's the win.
  2. Change 'BTC/USDT' to 'ETH/USDT' and run again. The number should be much smaller — that's Ethereum's price. You just re-pointed the bot at a new market.
  3. Change ticker['last'] to ticker['high']. Now you're reading today's high instead of the last price. Same data, different label.
