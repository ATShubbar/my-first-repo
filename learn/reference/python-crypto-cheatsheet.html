Python + ccxt Cheat Sheet

The compressed essence of what you've learned, built for quick lookup — not for reading cover to cover. Each entry links back to the lesson that taught it.

Setup (one time)

pip install ccxt        # install the library (Python's "app store")
python price.py         # run a script you've saved

Read a live price — Lesson 2

import ccxt                                   # borrow the library

exchange = ccxt.binance()                     # pick an exchange (or .kraken(), .coinbase())
ticker   = exchange.fetch_ticker('BTC/USDT')  # snapshot of one market (no API key needed)

print(ticker['last'])                         # last traded price
print(ticker['bid'])                          # best buy offer
print(ticker['ask'])                          # best sell offer
print(ticker['high'])                         # today's high
print(ticker['low'])                          # today's low

Vocabulary so far

  • Library — borrowed code you import. (ccxt talks to exchanges.)
  • pip — installs libraries from the terminal.
  • Variable — a named box: name = value.
  • Method — an action an object can do: object.action().
  • Dictionary — labelled values; read one with dict['label'].
  • Symbol — the market, e.g. 'BTC/USDT' = trade BTC priced in USDT.
Safety reminder: reading prices is public and free. An API key is only needed to place orders — and we stay in paper/dry-run mode until a strategy is proven.
